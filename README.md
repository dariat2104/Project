# Bubble-Tea Café Web Application (MVP)

## Проблема
Клієнти bubble-tea кафе стикаються з труднощами під час замовлення:
- черги та тривалий час очікування;
- складність перегляду меню й акцій в одному місці;
- відсутність бонусної системи для постійних клієнтів;
- складність пошуку найближчого закладу та маршруту до нього.

---

## Пітч та Цільова аудиторія
**Пітч:** Bubble-Tea Café Web — простий вебзастосунок для перегляду меню, онлайн-замовлення напоїв, отримання бонусів та швидкого пошуку найближчих bubble-tea закладів.  

**Цільова аудиторія:** молодь і студенти, відвідувачі bubble-tea кафе, постійні клієнти, які хочуть швидко замовляти напої та отримувати бонуси.

---

## Мета (Goal)
Створити MVP, який дозволяє користувачам:
- переглядати меню напоїв;
- оформлювати онлайн-замовлення;
- авторизуватись і накопичувати бонуси;
- переглядати акції та знижки;
- знаходити найближчі заклади та відкривати маршрут до них.

---

## MVP (Ключовий сценарій)
Користувач:
1. Відкриває сайт і переглядає меню.
2. Обирає напій і оформлює онлайн-замовлення.
3. Авторизується або входить у свій акаунт.
4. Отримує бонуси за замовлення.
5. За потреби відкриває розділ «Заклади поруч».
6. Обирає заклад і переглядає маршрут до нього на карті.

---

## Критерії успіху та приймання
- Меню відкривається і читається без помилок.  
- Замовлення оформлюється ≤ 60 секунд.  
- Авторизація працює коректно.  
- Бонуси нараховуються після замовлення.  
- Новий користувач може зробити замовлення без інструкцій.  
- Відкриття маршруту до закладу працює.  
- Відсутні критичні помилки під час тестування.
